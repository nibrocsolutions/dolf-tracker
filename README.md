# Dolf Tracker

A personal disc golf tracker for courses, live scoring, round history, and stats.

Scores and courses stay in this browser. Export a backup from Stats before clearing site data. The four starter courses are sample layouts with made-up hole data, so edit them or add your own.

## Scripts

```bash
npm install
npm test
npm run dev
```

The dev server listens on port 3000. `npm run typecheck` and `npm run build` check the app before a production build.
